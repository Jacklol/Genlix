# Каталог Праймбиф / Праймфудс от 29.10.2026

Источник: `source.xlsx` — исходный файл пользователя «ПРАЙБИФ для сайта.xlsx», сохранён без изменений. SHA-256 находится в `catalog.json`.

Подготовлено 173 товара: 111 Primebeef и 62 Праймфудс. У 43 замороженных позиций Primebeef есть аннотации и рекомендации по приготовлению. Два дополнительных листа аннотаций повторяют эти же артикулы и отдельно не импортируются.

`catalog.json` содержит поля формы CMS, исходное название и номер строки для каждого артикула. Аннотации внесены в поле «Описание», рекомендации сохранены в его конце. Короткие названия способов приготовления заполняются только по имеющемуся тексту. У остальных товаров краткое описание составлено из названия, состояния, бренда и веса из файла.

Охлаждённые и замороженные товары, грейды и варианты разделки сохраняются отдельными позициями. Идентификатор сопоставления — бренд и артикул. Существующие товары и их адреса сохраняются. Повторный запуск пропускает уже имеющиеся артикулы, включая черновики и архивные товары, сохраняя последующие правки и фотографии.

Фотографий в источнике нет. Главное фото и галерея пустые, на сайте используется стандартная заглушка. Страна и температуры хранения в файле не указаны: страна — «Не указана», температурный режим — согласно маркировке. Поставка оформлена как HoReCa, тип упаковки — короб; точные веса и количество перенесены из таблицы без расчёта недостающих значений.

Числовые столбцы цен сохранены только в `source` внутри пакета и в исходном файле. На сайт не выводятся. На листе Primebeef у 68 строк числа стоят под заголовками аннотаций: назначение и валюта этих чисел не предполагались.

## Проверка и загрузка в локальный проект

```sh
node scripts/prepare-primebeef-import.mjs
node scripts/import-primebeef.mjs
node scripts/import-primebeef.mjs --apply
```

Первый шаг воспроизводит подготовку из исходного файла. Второй показывает план без изменения каталога. Третий добавляет товары в локальную CMS новой ревизией с сохранением истории. Команда намеренно работает только с локальной CMS. Данные опубликованного сайта хранятся отдельно в Supabase и требуют импорта через админку после публикации поддержки товаров без фото.

- 65079, фарш Лайт: в названии 2 кг, в колонке веса единицы 8 кг, короба 2 кг, количество 4. Оба поля веса оставлены пустыми до уточнения.

- 60696: «2,кг» приведено к «2».
- 66815: в скопированной аннотации Top Choice ошибочно упоминался Prime — исправлено на грейд из строки товара.
- 66085: у незачищенной вырезки убраны указания Defatted и процента зачистки зачищенной вырезки.
- 66162: из аннотации убран вес 1,5–1,8 кг, противоречащий структурированной спецификации 1,3 кг.
- 79925: из приготовления Флэнка удалён приклеенный фрагмент про Бавет.
- 66160: восстановлен порядок фрагментов Бавета и удалён повтор приготовления.

В аннотациях также удалены служебные заголовки частей туши, исправлены очевидные переносы и артефакты распознавания. Исходные тексты доступны в `source.xlsx`.
